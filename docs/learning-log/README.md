# AU-STELLAR LIFE Website — Employer-Facing Development Log

This log documents the design and development of the AU-STELLAR LIFE website as a professional software engineering portfolio project.

Each entry records a meaningful project increment, including:

- The business problem and delivered outcome
- Architecture and implementation decisions
- Technologies and engineering practices used
- Testing and verification performed
- Security and privacy considerations
- Current limitations and next steps

The entries distinguish completed functionality from planned work. They avoid customer information, credentials, private coaching material, and sensitive implementation details that could increase risk to the live application.

## Project

- **Production site:** https://liveaustellarlife.com
- **Frontend:** React, TypeScript, HTML, and CSS
- **Build tooling:** Vite and npm
- **Delivery:** GitHub Actions and GitHub Pages
- **Version control:** Git and GitHub
