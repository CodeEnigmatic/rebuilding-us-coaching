# AU-STELLAR LIFE Website — Resume Project Report

**Live website:** https://liveaustellarlife.com  
**Repository:** https://github.com/CodeEnigmatic/rebuilding-us-coaching

## Project summary

Designed, developed, and launched the AU-STELLAR LIFE brand website, a responsive digital experience presenting personal-development programs, relationship and community frameworks, merchandise, book content, and video media.

## Technical work completed

- Built the website with React 19, TypeScript, Vite, HTML, and responsive CSS.
- Created reusable components and structured TypeScript data models.
- Developed a merchandise storefront interface with product variants, size selection, cart quantity controls, and live subtotal calculations.
- Designed cumulative Academy membership presentations for Individual, Relationship, and Community programs.
- Integrated responsive YouTube media and external book-purchase content.
- Optimized image assets to improve page performance and mobile delivery.
- Configured automated production builds and deployment through GitHub Actions and GitHub Pages.
- Connected a custom Cloudflare-managed domain and configured DNS, SSL/TLS, and enforced HTTPS.
- Verified successful production builds and live secure delivery at `liveaustellarlife.com`.

## Result

Successfully took the project from a local website to a publicly accessible, secure production deployment. The site now serves as the digital foundation for future payment processing, member authentication, protected Academy content, and customer-order integrations.

## Resume bullet

Developed and launched a responsive React and TypeScript brand website using Vite, GitHub Actions, GitHub Pages, and Cloudflare; implemented reusable UI components, a merchandise cart experience, optimized media delivery, custom-domain DNS, and enforced HTTPS.
